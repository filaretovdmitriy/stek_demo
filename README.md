# PostgreSQL и PHP в Docker Compose

## Запуск

Из каталога проекта выполните:

```bash
docker compose up --build -d
```

При первом запуске PostgreSQL автоматически создаст таблицы, тестовые данные и
функцию `абоненты_с_задолженностью` из файла
`docker/postgres/init/01-schema.sql`.

## Вызов функции PostgreSQL

```bash
docker compose exec postgres psql -U stek -d stek -c \
  "select * from абоненты_с_задолженностью('2021-07-01', 2);"
```

Ожидаемый результат содержит Иванова Ивана Ивановича и ЗАО «Развитие».
Отсутствующие значения отображаются как `[NULL]`. В самой базе они остаются
настоящими SQL-значениями `NULL`, а не строками.

## Запуск index.php

После запуска контейнеров откройте:

<http://localhost:8080>

Также файл можно выполнить из командной строки:

```bash
docker compose exec php php /var/www/html/index.php
```

Исходный PHP-файл находится в `src/index.php`. Изменения в нём сразу доступны
в контейнере, пересобирать образ не нужно. Он читает маршруты из
`src/routes.txt` и выводит маршруты, начальный ID которых не встречается среди
конечных ID. В файле маршрутов используется разделитель `;`, поскольку адреса
могут содержать запятые.

## Остановка

```bash
docker compose down
```

SQL-файлы инициализации запускаются только при первом создании тома PostgreSQL.
Чтобы пересоздать учебную базу после изменения SQL, удалите её том и запустите
контейнеры заново:

```bash
docker compose down -v
docker compose up --build -d
```

Команда `docker compose down -v` удаляет данные PostgreSQL из Docker-тома.
